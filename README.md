# Finance Investment Survey Analysis

Analysis of investment behavior among 40 young investors (age 21-35) using SQL and Power BI.

## Tools Used
- PostgreSQL (data storage, 22+ SQL queries, views, window functions)
- Microsoft Excel (data cleaning)
- Power BI (dashboard with 5 interactive visuals)

## Key Techniques
- Normalized 2-table schema with foreign keys
- Generated columns (auto-computed age_group)
- Window functions: RANK() OVER, COUNT() OVER PARTITION BY
- 3 reusable SQL views

## Key Insights
- Mutual funds are the most preferred investment avenue
- Majority of investors expect 20-30% returns
- Most invest for wealth creation, holding 1-5 years
